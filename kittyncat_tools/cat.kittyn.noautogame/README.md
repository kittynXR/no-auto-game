# cátte — NoAutoGame

Prevents Unity Game window from auto-opening or auto-focusing when entering play mode.

## Features
- Auto Unfocus: Prevents Game window from stealing focus when entering play mode
- Auto Close: Automatically closes Game window if it wasn't open before play mode
- Preserves your workflow by keeping focus on the windows you were actually using

## Installation
Install via VRChat Creator Companion (VCC) or add to your Unity project's Packages folder.
